# 🎡 人生の輪（Wheel of Life）

人生を10の領域に分け、それぞれに5つの問いを立てて、いまの人生のかたちを1枚の輪として視覚化する対話アプリ。

公開URL: https://arieru39.github.io/ariel-apps/life-wheel/

## 10の領域

お金／キャリア・仕事／健康・フィットネス／遊び・余暇／環境／コミュニティ／家族・友人／パートナー・恋愛／成長・学び／精神の豊かさ

## 各領域で答える5つの問い

| | 問い |
|---|---|
| ① | 現状の満足度を1〜10で採点 |
| ② | 現状ではどんなことをしているか |
| ③ | 理想の点数 |
| ④ | 理想形（具体的にどうしたいか） |
| ⑤ | 理想形に変えるためのアイデアや行動 |

## 設計思想

- **点数の高低ではなく、現状と理想のギャップを見る。** 低い領域が問題なのではなく、ギャップの大きい領域が「いま手をつけると効く場所」。
- **理想は10点でなくてよい。** 自分にとっての「これで十分」を③に置く。
- **⑤は最後に1つだけ選ぶ。** 結果画面はギャップ上位3領域の⑤だけを抜き出して「最初の一歩」を迫る。

## 機能

- 10ステップのウィザード（番号ドットで任意の領域へジャンプ可）
- 10分割の輪をSVGで描画（塗り＝現状／橙の点線＝理想）
- ギャップ順の一覧表、平均スコア、輪の「まるさ」
- localStorage 自動保存（送信なし・途中再開可）
- Markdownコピー／`.md`保存（Obsidian用フロントマター付き）／輪のPNG保存／PDF印刷

## 技術

単一 `index.html`。ビルド不要、依存ライブラリなし、外部通信なし。
