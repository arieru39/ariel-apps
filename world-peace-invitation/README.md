# 🌍 世界平和への招待状 — 主人公として関わり、オーナーとして担う

原著：『一人への貢献から世界平和へ―主人公として関わり、オーナーとして担う招待状』

## 📖 本の主張（1文）

**個人の「たまかつの火」→ 二者の盟約 → エコシステム八原理へと折り返す3層のフラクタル構造を、主人公として生き、オーナーとして担うことが、世界平和への最短経路である。**

## 🗺 3層構造 × 11テーマ

### 第1層 · 主人公の火（自分自身の起点）
1. **たまかつの火** — 主人公と傍観者の分岐（`tamakatsu_fire`／⭐️ 最初の扉）
2. **「誰の何に役立つか」** — 資質を強みに変える文法（`who_what_grammar`）
3. **個人版・自律自転の五原理** — 自分を主人公として束ねる（`personal_five_principles`）
4. **認知強化と熟達** — たまかつを支える二つの土台（`cognition_and_mastery`）

### 第2層 · 二者の盟約（目の前の一人への貢献）
5. **フラクタルの最小単位** — 世界の原子は二者関係（`fractal_smallest_unit`）
6. **二者関係の盟約** — 世界の最小の平和単位（`dyadic_covenant`）
7. **場への与贈性** — 非ゼロサムの主人公性（`contribution_to_field`）
8. **たまかつの枯渇の五経路** — 崩壊の早期警戒リスト（`five_paths_of_collapse`）

### 第3層 · オーナーとして担う（エコシステムの設計と世界平和）
9. **コンセプト・モデル・ストーリー** — 場を立ち上げる三層（`three_layer_structure`）
10. **エコシステムの盟約原理** — 八原理と循環の閉じ方（`ecosystem_eight_principles`）
11. **オーナーとして担う** — 四つの責任と世界平和（`owner_four_responsibilities`）

## 🔄 中核ループ

```
個人（たまかつの火）
   ↓ 火が立つと
二者（盟約による貢献）
   ↓ 盟約が編めると
場（八原理のエコシステム）
   ↓ 場が回ると
世界（平和のフラクタル）
   ↓ 折り返して
個人（次のたまかつ火を灯す）
```
