# GRIT — やり抜く力（学習アプリ）

Angela Duckworth『GRIT やり抜く力』を題材にした、ありえる楽考スタイルの学習アプリ。

**公開URL**: https://arieru39.github.io/ariel-apps/grit/

## 本の主張（1文）

> 才能ではなく、長期的な目標に向けた **「情熱」と「粘り強さ」** ──やり抜く力（GRIT）が、大きな成果を分ける。そして **やり抜く力は伸ばせる**。

## 3層構造 × 12テーマ

### 第1層 · GRITとは何か（定義と土台）
1. **grit_definition** — 情熱と粘り強さ（GRITの定義）★ 最初の扉
2. **talent_myth** — 才能神話の罠
3. **effort_equation** — 努力の方程式（努力は2度掛かる）
4. **grit_scale** — 自分のグリット・スコア

### 第2層 · 内側から伸ばす
5. **grit_is_grown** — やり抜く力は伸ばせる（遺伝×経験）
6. **deepen_interest** — 興味を掘り下げる
7. **deliberate_practice** — 意図的な練習
8. **purpose_beyond_self** — 目的（他者への貢献）
9. **growth_hope** — 希望と成長マインドセット

### 第3層 · 外側から伸ばす
10. **wise_parenting** — 賢明な子育て（温かく×厳しく）
11. **hard_thing_rule** — ハードなことに挑戦するルール（課外活動）
12. **grit_culture** — GRIT文化

## 中核ループ

1. **4択の関係性クイズ（12問）** で12テーマ全体の関係を掴む
2. **第1層から順に** 各テーマの観点クイズを解く（動画を観る前の観点づくり）
3. **動画を観る**（各LOに対応する rubric-advancement 動画）
4. **ルーブリック L1→L4** で自分の現在地を測り、次の段階への行動を選ぶ

## 動画運用

各テーマの `video_embed_url` には **ルーブリック前進動画（L1→L2→L3→L4 の背中を押す動画）** を埋め込む。動画は `07プロンプト/プロンプト/プロンプト_GRITルーブリック前進動画をつくる.md` の指示書で NotebookLM／音声合成／手撮り等で制作。

## ありえる楽考との接続

- GRITは **貢献志向**（目的が他者に向く）で長期化する（第8章）
- 意図的な練習は **判断軸の内部化**（Slow→Fastの沈殿）と同型（第7章）
- GRIT文化は **場のデザイン**（周囲がお互いを引き上げる）そのもの（第12章）
