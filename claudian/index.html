Claudian 導入マニュアル
― Obsidian を AI と一緒に使えるようにする ―

Obsidian の中で Claude Code を動かすプラグイン「Claudian」を、まっさらな PC からセットアップするための手順書です。ターミナルを触ったことがない方でも、上から順番になぞれば完了します。

対象：Mac / Windows（デスクトップ版） 所要時間：およそ 30〜45 分 前提知識：不要 最終更新：2026年7月
お使いの PC を選んでください
切り替えると、以下の手順が選んだ OS 用に入れ替わります。

Claudian とは何か

Claudian は、メモアプリ Obsidian の中に AI（Claude Code）を住まわせるための無料プラグインです。Obsidian の保管庫（Vault）がそのまま AI の作業場所になるので、「自分のメモを読ませて、書かせる」ことができます。

Claudian で できるようになること

  • 自分のノートを読ませて相談できる — 「先週の議事録をまとめて」のように、Vault 内のファイルを根拠に答えてもらえる
  • ノートを AI に書かせる・直させる — 新規ファイルの作成、既存ノートの追記・整形まで実行できる
  • 複数ファイルをまたいだ作業 — 「日次メモ 30 件から今月の振り返りノートを作る」といった一括処理
  • 文章の部分編集 — 選択した段落だけを、変更前後の差分を見ながら書き換え
  • 定型作業の登録 — よく使う指示をスラッシュコマンドとして保存し、いつでも呼び出し

全体の流れ（ここで作るもの）

セットアップは大きく 3 つの部品を揃える作業です。順番が大事なので、飛ばさずに進めてください。

部品役割担当 STEP
Obsidianメモを書くアプリ本体。ここが「家」になります。STEP 1〜2
Claude Code実際に考えて作業する AI 本体。PC 側にインストールします。STEP 3〜5
Claudian上の 2 つをつなぐ配管。Obsidian のプラグインとして入れます。STEP 6〜8
用語メモ

Vault（ヴォールト／保管庫）…Obsidian がメモを保存するフォルダのこと。プラグイン…アプリに機能を追加する部品。ターミナル / PowerShell…文字で PC に命令する画面。STEP 3 で開き方から説明します。

0STEP 0：始める前の準備チェック

ここで足りないものがあると途中で止まります。先に確認しておきましょう。

必要なもの

  • Claude の有料プラン（Pro / Max / Team / Enterprise）または Claude Console の API 契約。無料プランでは Claude Code は使えません。
  • インターネット接続
  • メモリ 4GB 以上の PC
  • macOS 13.0（Ventura）以降
  • Windows 10（バージョン 1809）以降、または Windows 11
  • 作業時間 30〜45 分（途中でブラウザのログイン操作が入ります）
Mac 版

OS のバージョンを確認する方法

  1. 画面左上の アップルマーク（） をクリック
  2. 「このMacについて」 を選択
  3. 表示された数字が 13 以上 であれば OK（例：macOS 15.x）
Windows 版

OS のバージョンを確認する方法

  1. キーボードの Windows + R を同時に押す
  2. 出てきた小窓に winver と入力して Enter
  3. Windows 10 バージョン 1809 以降、または Windows 11 であれば OK
Node.js は必要ですか？

このマニュアルで案内する方法（公式インストーラー）では Node.js のインストールは不要です。ネット上の古い記事では「先に Node.js を入れる」と書かれていることがありますが、現在は不要になっています。すでに入っていても問題ありません。

1STEP 1：Obsidian をインストールする

すでに Obsidian を使っている方は、この STEP と STEP 2 を飛ばして STEP 3 へ進んでください。

Mac 版
  1. ブラウザで obsidian.md/download を開きます。
  2. macOS 用のダウンロードボタンをクリックします（.dmg ファイルが落ちてきます）。
    ※ Apple シリコン（M1〜M4）／Intel の選択肢が出た場合は、STEP 0 の「このMacについて」で見たチップ名に合わせて選びます。迷ったら「Apple Silicon」を選んでください。
  3. ダウンロードした Obsidian-x.x.x.dmg をダブルクリックします。
  4. 開いたウィンドウで、Obsidian のアイコンを Applications フォルダにドラッグ＆ドロップします。
  5. Launchpad または「アプリケーション」フォルダから Obsidian を起動します。
  6. 「インターネットからダウンロードされたアプリです」と確認が出たら 「開く」 をクリックします。
Windows 版
  1. ブラウザで obsidian.md/download を開きます。
  2. Windows 用のダウンロードボタンをクリックします（.exe ファイルが落ちてきます）。
  3. ダウンロードした Obsidian-x.x.x.exe をダブルクリックします。
  4. 「WindowsによってPCが保護されました」 と青い画面が出た場合は、「詳細情報」→「実行」 の順にクリックします。
  5. インストールが自動で進み、完了すると Obsidian が起動します。
補足

Microsoft Store 版ではなく、公式サイトの .exe 版を使ってください。Store 版はフォルダの扱いが異なり、プラグインで問題が起きることがあります。

2STEP 2：Vault（保管庫）をつくる

Vault は「メモを入れておくフォルダ」です。この Vault が、そのまま AI の作業場所になります。

  1. Obsidian を起動すると、最初に 「Create new vault（新規保管庫を作成）」 という画面が出ます。
  2. Vault name に好きな名前を入力します（例：MyNotes）。
  3. Location（場所） の「Browse」を押して、保存先フォルダを選びます。
    「書類（Documents）」フォルダの中がおすすめです。
    「ドキュメント」フォルダの中がおすすめです。
  4. 「Create」 をクリックすると、空の Vault が開きます。
Vault の置き場所で気をつけること
  • フォルダ名・パスに日本語やスペースを含めないことを強くおすすめします（例：MyNotes は OK、私のメモ 2026 は避ける）。AI がファイルを扱うときにトラブルが起きにくくなります。
  • iCloud Drive の中は避けてください。ファイルが自動で「クラウドのみ」に退避され、AI から読めなくなることがあります。
  • OneDrive の中は避けてください。「ファイルオンデマンド」により実体がローカルに無い状態になり、AI から読めなくなることがあります。

3STEP 3：ターミナルを開く

ここから 2 STEP だけ、黒い画面（ターミナル）を使います。コピー＆ペーストするだけなので、身構えなくて大丈夫です。

Mac 版：ターミナルの開き方
  1. キーボードの command ⌘ + スペース を同時に押します（Spotlight 検索が開きます）。
  2. ターミナル と入力します（英語環境なら Terminal）。
  3. 一覧の先頭に出てくる 「ターミナル」 を選んで Enter。
  4. 白または黒のウィンドウが開き、ユーザー名@Mac ~ % のような文字が表示されれば準備完了です。
ターミナルの使い方の基本
  • コマンドは コピーして貼り付け（command ⌘ + V）→ Enter で実行します。
  • パスワードを入力する場面では、打っても画面に何も表示されません。これは正常です。そのまま入力して Enter を押してください。
  • 処理中は何も反応がないように見えることがあります。1〜2 分は待ちましょう。
Windows 版：PowerShell の開き方
  1. キーボードの Windows キーを押します。
  2. powershell と入力します。
  3. 一覧に出てくる 「Windows PowerShell」 を選んで Enter。
    ※ 管理者として実行する必要はありません。通常起動で大丈夫です。
  4. 青または黒のウィンドウが開き、PS C:\Users\あなたの名前> のような文字が表示されれば準備完了です。
ここが最重要：PowerShell と コマンドプロンプトは別物です

行頭に PS が付いていれば PowerShell、付いておらず C:\...> だけなら コマンドプロンプト（CMD）です。このマニュアルの Windows 手順は PowerShell 用です。PS が見当たらない場合は、いったん閉じて開き直してください。

PowerShell の使い方の基本
  • コマンドは コピーして貼り付け（Ctrl + V、または右クリック）→ Enter で実行します。
  • 処理中は何も反応がないように見えることがあります。1〜2 分は待ちましょう。

4STEP 4：Claude Code をインストールする

AI の本体をインストールします。開いたターミナルに、下のコマンドをそのまま貼り付けて実行してください。

Mac 版

インストールコマンド

curl -fsSL https://claude.ai/install.sh | bash

貼り付けたら Enter。ダウンロードとインストールが自動で進みます（1〜3 分程度）。

インストールできたか確認する

いったんターミナルを 閉じて、開き直してから、次を実行します。

claude --version

2.1.211 (Claude Code) のようにバージョン番号が表示されれば成功です。

command not found: claude と出たら

ターミナルを開き直していない可能性が高いです。ターミナルを完全に終了（command ⌘ + Q）してから開き直し、もう一度試してください。それでも直らない場合は 「困ったときは」 を参照してください。

Homebrew を使っている方へ

すでに Homebrew を使い慣れている場合は brew install --cask claude-code でも導入できます。ただし Homebrew 版は自動更新されないため、こだわりがなければ上のコマンドを推奨します。

Windows 版

インストールコマンド（PowerShell）

irm https://claude.ai/install.ps1 | iex

貼り付けたら Enter。ダウンロードとインストールが自動で進みます（1〜3 分程度）。

エラーが出たときの見分け方
  • 'irm' is not recognized... → PowerShell ではなく コマンドプロンプトを開いています。PowerShell を開き直してください。
  • スクリプトの実行がシステムで無効になっています → 下の 1 行を実行してから、もう一度インストールコマンドを試してください。
    Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
    （Y と入力して Enter で承認します）

インストールできたか確認する

いったん PowerShell を 閉じて、開き直してから、次を実行します。

claude --version

2.1.211 (Claude Code) のようにバージョン番号が表示されれば成功です。

（推奨）Git for Windows を入れておく

必須ではありませんが、入れておくと Claude Code が使えるコマンドの種類が増え、動作が安定します。

  1. git-scm.com/downloads/win からインストーラーをダウンロード
  2. ダブルクリックして起動し、設定はすべて初期値のまま「Next」を押し続けてインストール

入れなくても Claudian は動きます。後からでも追加できます。

5STEP 5：Claude にログインする

インストールした AI に、あなたの Claude アカウントを紐づけます。この作業は最初の 1 回だけです。

  1. ターミナル（PowerShell）で、次のコマンドを実行します。
    claude
  2. 初回はログイン方法を聞かれます。キーボードの上下キーで選び、Enter で決定します。
    • Claude の有料プラン（Pro / Max など）を使う場合 → サブスクリプションでのログインを選択
    • API キーで使う場合 → Console / API キーの選択肢を選ぶ
  3. 自動的に ブラウザが開きます。Claude アカウントでログインし、表示された内容を確認して 承認します。
  4. ブラウザに認証コードが表示された場合は、それをコピーしてターミナルに貼り付け、Enter。
  5. ターミナルに Claude Code の対話画面が表示されたら成功です。試しに こんにちは と打って返事が返ってくるか確認しましょう。
  6. 確認できたら /exit と入力して Enter、または Ctrl + C を 2 回押して終了します。
ここまで来れば山場は越えました

残りはすべて Obsidian の画面上でのマウス操作です。ターミナルはいったん閉じて構いません。

6STEP 6：Claudian プラグインを入れる

Obsidian の画面に戻り、プラグインを追加します。ここからは Mac / Windows で操作は共通です（ショートカットキーだけ異なります）。

  1. Obsidian を起動し、STEP 2 で作った Vault を開きます。
  2. 左下の 歯車アイコン（⚙ Settings） をクリックして設定を開きます。
    ショートカット：command ⌘ + ,Ctrl + ,
  3. 左メニューから 「Community plugins（コミュニティプラグイン）」 を選びます。
  4. 初回のみ 「Turn on community plugins（コミュニティプラグインを有効化）」 というボタンが出るので、クリックして有効にします。
    ※ 「制限モードをオフにする」と表示される場合もあります。同じ操作です。
  5. 「Browse（閲覧）」 ボタンをクリックします。
  6. 検索欄に Claudian と入力します。
  7. 検索結果から 作者が「Yishen Tu」の「Claudian」 を選びます。
    似た名前のプラグインに注意

    ストアには 「ClaudianIA」 という別のプラグインも存在します。作者名が「Yishen Tu」であることを必ず確認してください。説明文に「embeds Claude Code/Codex as an AI collaborator in your vault」とあるものが正解です。

  8. 「Install（インストール）」 をクリックし、完了したら 「Enable（有効化）」 をクリックします。
  9. Obsidian の 左端のリボン（縦に並んだアイコン列）に Claudian のアイコン が追加されていれば成功です。
ストアに見つからない場合（手動インストール）
  1. GitHub のリリースページ から main.js / manifest.json / styles.css の 3 ファイルをダウンロード
  2. Vault フォルダの中に .obsidian/plugins/claudian/ というフォルダを作り、3 ファイルを入れる
    ※ .obsidian は隠しフォルダです。Finder で command ⌘ + shift + . を押すと表示されます。 ※ .obsidian は隠しフォルダです。エクスプローラーの「表示」→「隠しファイル」にチェックを入れると表示されます。
  3. Obsidian の Community plugins 画面で更新ボタンを押し、Claudian を有効化

7STEP 7：Claudian の初期設定

多くの場合、設定を触らなくてもそのまま動きます。まず STEP 8 の動作確認を先に試し、うまくいかないときだけここに戻ってきてください。

設定画面の開き方

Obsidian の 設定（⚙） → 左メニューの下のほうにある 「Claudian」 をクリックします。

確認しておきたい項目

項目設定内容
Provider（プロバイダー）Claude になっていることを確認します。初期値のままで OK です。
Claude CLI path
（Advanced タブ内）		空欄のままにしておきます。空欄だと自動検出されます。動かないときだけ、下の手順で手入力します。
Environment（環境変数）通常は何も入れません。

自動検出に失敗したとき：CLI パスを手入力する

Mac 版
  1. ターミナルを開き、次を実行します。
    which claude
  2. 表示されたパス（例：/Users/あなたの名前/.local/bin/claude）をすべてコピーします。
  3. Obsidian の 設定 → Claudian → Advanced → Claude CLI path に貼り付けます。
  4. Obsidian を再起動します。
Windows 版
  1. PowerShell を開き、次を実行します。
    where.exe claude
  2. 表示されたパスのうち、claude.exe で終わるものをコピーします（例：C:\Users\あなたの名前\.local\bin\claude.exe）。
  3. Obsidian の 設定 → Claudian → Advanced → Claude CLI path に貼り付けます。
  4. Obsidian を再起動します。
Windows でのパス指定の鉄則
  • 指定するのは claude.exe です。
  • .cmd や .ps1 で終わるパスは指定しないでください。正しく起動できません。
  • npm で入れた場合のみ、npm root -g で表示されたフォルダ内の cli-wrapper.cjs を指定します（古い cli.js ではありません）。

8STEP 8：動作確認

最後に、ちゃんと動くか試してみましょう。

  1. Obsidian で 左端のリボンにある Claudian アイコン をクリックします。
    見つからない場合：command ⌘ + PCtrl + P でコマンドパレットを開き、Claudian: Open Chat と入力して実行します。
  2. 右側（または左側）に チャットパネル が開きます。
  3. 入力欄に、テスト用の指示を打ってみます。
    test.md というファイルを作って、中に「セットアップ完了」と書いてください。
  4. AI がファイル作成の 許可を求めてくる ので、内容を確認して 承認します。
  5. Vault の中に test.md が作られ、「セットアップ完了」と書かれていれば すべて完了です。
お疲れさまでした

これで、あなたのメモを読み書きできる AI が Obsidian の中に入りました。次のセクションで、実際に使うときの基本操作を押さえておきましょう。

完了チェックリスト

  • Obsidian が起動し、Vault が開ける
  • ターミナルで claude --version がバージョンを返す
  • Obsidian の左リボンに Claudian アイコンがある
  • Claudian のチャットパネルが開く
  • AI に指示してファイルが作れた

基本の使い方 5 つ

最初に覚えるのはこれだけで十分です。

① チャットで相談する

リボンの Claudian アイコンからチャットを開き、普通の日本語で指示します。会話はタブで複数持てるので、話題ごとに分けられます。過去の会話は履歴から呼び戻せます。

例：「このVaultにある読書メモを、著者別に整理した一覧ノートを作って」

② @ でファイルを指定する

チャット入力欄で @ を打つと、Vault 内のファイル候補が出ます。読ませたいノートを名指しすると、精度がぐっと上がります。

例：「@daily/2026-07-20.md を要約して @weekly/2026-W30.md に追記して」

③ / で定型コマンドを呼ぶ

/ を打つと登録済みのコマンド一覧が出ます。$ ではスキル（より大きな作業手順）を呼び出せます。よく使う指示を登録しておくと毎回打たずに済みます。

④ Plan Mode（計画モード）で安全に進める

Shift + Tab で切り替わります。オンにすると AI がいきなり実行せず、「何をするか」の計画を先に見せてくれます。承認してから実行されるので、大きな作業をさせるときは必ずオンにしてください。

⑤ Inline Edit（部分書き換え）

ノート内の文章を選択した状態でホットキーを押すと、小窓が開きます。「もっと簡潔に」などと指示すると、変更前後の差分が単語単位で表示され、納得してから適用できます。

ホットキーは 設定 → ホットキー で Claudian を検索して割り当てられます。

困ったときは（トラブル対処）

症状別・対処一覧

症状対処
spawn claude ENOENT
Claude CLI not found		 Claudian が Claude Code を見つけられていません。STEP 7 の「CLI パスを手入力する」 の手順でパスを指定してください。
nvm / fnm / volta などの Node バージョン管理ツールを使っている環境で特によく起こります。
Claudian のアイコンが出てこない 設定 → Community plugins で Claudian のスイッチが ON になっているか確認。ON なら Obsidian を完全に終了して再起動してください。
チャットは開くが返事が来ない ターミナルで claude を実行し、ログインが切れていないか確認します。切れていれば再ログインしてください。
claude --version が動かない ターミナルを完全に終了してから開き直してください。それでも駄目なら、STEP 4 のインストールコマンドをもう一度実行します。
もっと詳しく原因を調べたい ターミナルで claude doctor を実行すると、インストール状態と設定の診断結果が表示されます。
Node.js と claude の場所がずれている ターミナルで dirname $(which claude) と dirname $(which node) を実行し、結果が異なる場合は、設定 → Claudian → Environment に PATH=/Node.jsのbinへのパス を追加します。または STEP 4 の公式インストーラーで入れ直すのが確実です。
PowerShell でスクリプトが実行できない Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned を実行してから、インストールをやり直してください。
CLI パスを指定しても直らない 指定したパスが .cmd や .ps1 で終わっていないか確認してください。claude.exe を指定する必要があります。
スマホの Obsidian で使いたい できません。Claudian はデスクトップ版 Obsidian（Mac / Windows / Linux）専用です。
迷ったらこの 3 つ
  1. Obsidian を完全に終了して再起動する
  2. ターミナルを開き直して claude --version を確認する
  3. ターミナルで claude doctor を実行して診断結果を見る

安全に使うための注意点

Claudian は Vault の中のファイルを実際に書き換えます

チャット相手というより「あなたのフォルダで作業するアシスタント」です。以下の点を押さえておいてください。

  • 大事な Vault は必ずバックアップを取る。Obsidian Sync、Time Machineファイル履歴、あるいは Git などで履歴を残しておくと安心です。
  • 最初のうちは Plan Mode（Shift+Tab）を常にオンに。実行前に計画を確認できます。
  • 許可を求められたら内容を読む。ファイルの削除や上書き、コマンド実行の確認は流し読みせず承認してください。
  • 送信されるデータ。あなたの入力、添付したファイル、AI が読んだノートの内容は、設定したプロバイダー（Anthropic など）に送信されます。プラグイン自体は独自のデータ収集（テレメトリ）を行いません。
  • 設定の保存場所。Vault 内の .claudian/（プラグイン設定）と .claude/（Claude 関連ファイル）に保存されます。Git で管理している Vault なら、.gitignore にこの 2 つを追加しておくことをおすすめします。
  • 機密情報を含む Vault では慎重に。顧客情報や未公開情報を含む Vault を扱う場合は、社内ルールを確認してから使ってください。
