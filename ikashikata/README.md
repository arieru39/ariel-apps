# 🌿 わたしの活かし方 — 教わらずに育った力を、意図して使う90分

ありえる楽考の入口になる90分ワークショップの、**進行つきワークシート・アプリ**。
**オンライン実施に対応**（Zoom／Discord／Meet のブレイクアウトを前提）。

公開URL: https://arieru39.github.io/ariel-apps/ikashikata/

- 参加者モード（既定）: `#` なし
- 進行役モード: `#facil`
- 投影モード（画面共有用・大きい文字）: `#screen`

## これは何をするアプリか

| 段 | やること |
|---|---|
| ⓪ | 今日の約束（やらないこと5つ）を読む |
| ① | 前書きを**分担して音読**し、「どの一節で手が止まったか」を語り合う |
| ② | **母語を覚えたときに使っていた力**を1つ選び、**いま抜かれても生えてくるもの**を場面で書く |
| ③ | 3人組で**理由の2枚取り**（自分の理由／他の人が見た理由2つ）＋**活きる条件**を受け取る |
| ④ | **わたしの活かし方を1行にする**（空欄3つ）＋一区画を決める |
| ⑤ | 24時間以内の第一歩 → イナゴマメの木 → 閉じの反転 |

## 設計上、外してはいけない1点

活かし方の1行は3つの空欄でできている。

```
わたしの活かし方は、
  ［① 抜かれても生えてくるもの ］ を、
  ［② それが活きる条件         ］ に置いて、   ← 自分では埋められない
  ［③ 教わらずに育った力の使い方 ］ で使うことである。
```

**①と③は一人でも書ける。②だけは書けない。**
だから **②の欄は、受け取った条件からラジオボタンで選ぶことしかできない**実装にしてある。
まだ受け取っていない人には「これは不具合ではありません。②欄は、自分では書けない欄です」と出る。

> この制約を外すと、このワークショップは成立しない。
> 「自分では見えない」を体験として起こすことが、90分の出口だから。

## オンライン対応の中身

バックエンドを持たない（GitHub Pages の静的配信）ので、**リアルタイム同期はしない。**
代わりに **コピー＆ペーストの橋** を用意してある。

| 機能 | どこ |
|---|---|
| **条件をつくって渡す** → 貼り付け用の文を生成しコピー | ③-c（参加者） |
| **条件を受け取る** → チャットの文を貼り付けて取り込み（複数まとめて可） | ③-d（参加者） |
| 対面用の手入力フォールバック | ③-d「手で1つ足す」 |
| 読み上げ担当の自動割り当て（人数を入れる） | 進行役 |
| ブレイクアウトに貼る指示文（①／③／④） | 進行役 |
| 5枠のタイマー／③の7分ローテーション（5段・自動で次段へ・終了音） | 参加者・進行役 |
| オンライン段取り表・**オンライン固有の致命傷3つ** | 進行役 |

**貼り付け用の文の書式**（チャットでそのまま読める形にしてある）:

```
▼活きる条件（〇〇さんへ）
観察：発言していない人に、休憩時間に声をかけていた
条件：相手が助けを求めていて、断る自由もあるとき
差出人：田中
```

受け取り側は `観察：` / `条件：` / `差出人：` を抜き出す。`▼活きる条件` で区切るので**複数まとめて貼れる**。
書式が崩れていても、本文まるごとを条件として取り込むフォールバックがある。

## データの扱い

- 入力はすべて **localStorage（`ikashikata.v1`）にのみ保存**。サーバーに送らない
- 端末をまたがない。別端末で開くと空
- 最後に **持ち帰りカード**（コピー／`.txt` ダウンロード／印刷）
- 「入力を全部消す」で初期化（共用端末で回すとき用）

## 進行役モードに入っているもの（参加者に見せない）

- ファシリが必ず守ること5つ（①でまとめない／②は自分から先に出す／同業で組ませない／応答は1人1問／90分で解決して閉じない）
- **オンライン固有の致命傷3つ**と手当て
  1. 条件が渡らないまま③が終わる → **入る前に画面共有で1回やってみせる**
  2. ブレイクアウトのチャットが消えて受け取りが失われる → **残り3分でブロードキャスト**
  3. ④の②欄を自分で打ち直す → **アプリ側で選択のみに制限済み**

## 元になった設計

Obsidian vault 側に設計書と紙の冊子がある。

- 設計書（ファシリ用・v2）: `___ありえる楽考の入口になる90分ワークショップ/設計_90分WS_わたしの活かし方_v2.md`
- 紙の配布冊子（A5・8ページ）: `___ありえる楽考の入口になる90分ワークショップ/配布_冊子_わたしの活かし方.md`
- 前書きの原文: `___ありえる楽考の入口になる90分ワークショップ/_共通の問い.md`

**前書きの本文は一字も変えていない。** ①〜⑧の番号と、長い文の読み継ぎ位置（`／`）だけを足している。

## 技術

- 依存ゼロ・単一ファイル（`index.html` 約44KB）
- ビルド不要。`booklet/` と同じ「自己完結ツール型」。`_template/` の書籍学習アプリ型ではない
- 検証:
  ```bash
  python3 -c "import re; open('/tmp/js.js','w').write(re.search(r'<script>([\s\S]*?)</script>', open('index.html').read()).group(1))"
  node --check /tmp/js.js
  ```
