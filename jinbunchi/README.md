# 人文知は武器になる × ありえる楽考 — 三層整理

**公開URL**: https://arieru39.github.io/ariel-apps/jinbunchi/

## この本の主張（1文）

> AIによって「正解を出す力」がコモディティ化し、外部の「正しさ」が断片化した世界で、
> **判断を外部の権威に預けられなくなった人が、「いま、ここでどう判断するか」を自分で引き受けられるようになること。**

## このアプリ固有の設計 — 羅針盤ファースト

このアプリは、**学習者が最初に「何を目指すのか」を言葉で受け取り、それを羅針盤にして進む**ように設計されている。

**羅針盤（＝このアプリの尺度）**

> 目的は、本を「読めた」状態になることではない。
> 目指すのは、**自分の判断を1つ、外部の権威（数字・前例・偉い人・海外事例）を一切引かずに、自分の言葉で説明できる状態**である。

**なぜこの尺度なのか**

本書は「世界に対する解像度をあげ続ける以外に方法はない」と言う。しかし解像度は測れない。
だから本書は、同じ本の中でこう告発することになる ──「**自分はできていると思っている人のほとんどはできていません**」。

測れないものに「大事だ」を置くと、全員が「できている」に落ちる。
そこで、観測可能な代理尺度に置き換えている。

**羅針盤の3点セット（銀のバナー＋テーマ `compass` に常駐）**

| | |
|---|---|
| 🧭 **迷ったら戻る問い** | 「いま私は、外の話をしているのか、内の話をしているのか、決める話をしているのか？」 |
| 🎯 **進め方** | 全部を上げようとしない。いちばん低い1つだけが急所。**1段だけ登る** |
| 🏁 **終わり方** | 3領域のうちどれか1つが1段上がったら、このアプリは一周 |

## 中核ループ

```
🧭 羅針盤を読む（目的を言葉で受け取る）
      ↓
3領域（外・内・決める）で現在地を L1〜L4 で言い切る
   ※「あいだ」は禁止。迷ったら低いほう。均さない
      ↓
いちばん低い1つ ＝ 今の急所
      ↓
1段だけ登る（24時間以内 → 1週間 → 1ヶ月）
      ↓
1段上がったら一周。羅針盤に戻る
```

## ルーブリック（L1入門 → L4原則）

| 段 | ラベル | Fast/Slow 位相 |
|---|---|---|
| L1 | 入門｜気づいていない | Fast が自動で誤作動（Slow が起動していない） |
| L2 | 練習｜言えるが、動かない | Slow で意識すれば言えるが、場面では出てこない |
| L3 | 応用｜できる | Slow の反復で Fast に沈殿し始めた |
| L4 | 原則｜他者に渡せる・設計できる | **主語が他者か仕組みになる／自分がいなくても回る** |

> **L3とL4の差は程度ではない。** ヌスバウムのタゴール批判がそのまま境界になる ──
> 「タゴールの試みに欠けていたのは、自分がいなくても他の人間が同じ教育を続けられるよう、手法を定めることだった」

## 統一原理（engine_note）

> **測る物差しが無いところに「大事だ」を置くと、全員が「できている」に落ちる**
