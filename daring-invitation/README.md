# 弱さを抱いて誘う ─ ビジョンが明確になる旅（daring-invitation）

## 本の主張（1文）

**自分の弱さを分かち合いながらコミュニティのメンバーを誘い続けることで、自分のビジョンは初めて輪郭を得る。**

## 3書統合の学習アプリ

このアプリは以下の3つを **1つのループ** として学べるように統合しています：

| 出典 | 主な貢献 |
|---|---|
| 五百田達成『「誘える人」がぜんぶ手に入れる』 | 誘うことの実践知（もうちょっと話してみたい／店・人・コンテンツの3保険／断られる≠人格否定） |
| ブレネー・ブラウン『本当の勇気は弱さを認めること（Daring Greatly）』 | 弱さの再定義（Vulnerability is not weakness／グレムリンを黙らせる／競技場に立ち続ける） |
| 鈴木利和『たまかつ』16章「リクルーティング」 | ビジョンを社会への約束にして、たった20人の熱狂を集める（創造者の旅） |

## 11 テーマ × 3 層構造

### 第1層 · 自分の弱さから始める — 内側で「私はこれでよい」を取り戻す

1. `own_your_story` — 弱さは弱点ではない
2. `silence_the_gremlin` — グレムリン（内なる批判者）を黙らせる
3. `find_your_who` — あなたの『誰』を見つける

### 第2層 · 誘う — 弱さを足場に、他者に手を差し伸べる

4. `soft_invitation` — もうちょっと話してみたい、を届ける
5. `three_insurances` — 店・人・コンテンツの3保険
6. `share_your_shame` — 先に弱さを開く
7. `refusal_is_not_rejection` — 断られる ≠ 人格否定

### 第3層 · ビジョンを明確にする — 招待の連続がビジョンを輪郭化する

8. `speak_the_vision` — ビジョンを社会への約束にする
9. `twenty_evangelists` — たった20人の熱狂
10. `daring_community` — 弱さを分かち合えるコミュニティを自炊する
11. `stay_in_the_arena` — 競技場に立ち続ける

## 中核ループ

```
自分の弱さを認める（Layer 1）
    ↓ 「私はこれでよい」の内側の土台ができる
弱さを開いて誰かを誘う（Layer 2）
    ↓ 招待の連続の中で、共鳴する人・拒む人が可視化される
ビジョンが社会への約束として輪郭を得る（Layer 3）
    ↓
たった20人の熱狂 → 弱さを分かち合えるコミュニティ → 競技場に立ち続ける
```
